# 知识库使用说明

知识库用于保存经过确认的业务背景、字段定义、指标解释和分析规则，让 Agent 在当前工作区内引用稳定的上下文。

## 使用流程

1. 打开「知识库」，选择当前工作区。
2. 上传经过授权的 PDF、DOCX、XLSX、CSV 或文本文件。
3. 检查文件名称、来源和解析状态；结构化表格优先确认工作表和字段。
4. 预览解析内容，删除不应进入检索范围的片段，并手动修正必要的定义。
5. 只启用已经审核过的条目，再回到对话中提出分析问题。

## 使用建议

- 每条知识尽量只描述一个业务概念、字段口径或操作规则；
- 同名指标应保留来源和版本，避免不同定义被混用；
- 知识库内容只用于辅助理解，不会替代当前数据中的实际计算结果；
- 禁用或删除条目后，新分析不会主动引用它，但历史结果仍按原运行记录保存。

## 数据与权限

上传内容必须来自合法授权的数据范围。不要上传密码、API Key、Cookie 或不必要的个人敏感信息。知识库检索会受当前工作区、用户权限、模型配置和文件解析能力影响；解析成功不等于内容已经经过业务核验。
