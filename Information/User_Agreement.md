# PFS 数据分析 Agent · 使用与数据处理说明

> 本说明适用于 PFS 本地工作台。若将 PFS 部署为托管服务，服务提供方应根据实际运营主体、部署区域和数据处理方式另行发布相应的服务条款与隐私说明。

## 1. 服务范围

PFS 是一个用于文件、数据库和团队分析任务的 Agent 工作台。它可以连接用户指定的数据源，执行受控查询和分析，并生成图表、文档、演示文稿或其他 Artifact。具体能力受版本、配置、权限和运行环境限制。

## 2. 用户责任

用户应确保对上传、挂载、查询或写回的数据拥有合法权利，并自行确认数据中是否包含个人信息、商业秘密或其他受保护内容。用户不得利用 PFS 违反法律法规、第三方协议或数据源权限规则。

用户应保护自己的 API Key、账号凭据、工作区路径和生成文件，不得将其提交到代码仓库或公开日志中。

## 3. AI 结果边界

模型输出、SQL、统计分析和自动生成的解释可能存在错误、遗漏或不适用情况。PFS 的结果用于辅助分析，不替代用户对口径、数据质量、业务背景和最终决策的独立判断。

系统会尽力保留工具调用、数据引用、运行状态和错误信息，但“有引用”不代表结论天然正确；用户仍应核对原始数据和指标定义。

## 4. 外部操作

读取、计算和展示与创建分析表、清洗数据、写回外部系统、发送消息或其他副作用不同。外部操作应在明确的用户意图、权限、范围、幂等控制和审计记录基础上执行。当前并非所有副作用路径都已经接入统一 PFS 审批门。

## 5. 数据处理

本地部署时，数据保存位置由部署者和本机环境决定；托管部署时，数据处理范围、保留期限、删除方式、子处理方和跨境安排必须以实际部署方发布的隐私说明为准。当前仓库本身不构成对任何托管服务等级或数据保留期限的承诺。
