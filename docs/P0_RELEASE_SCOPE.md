# PFS P0 发布范围锁定

> 锁定日期：2026-09-06
> 状态：范围冻结；P0 本地质量门和核心闭环契约已通过，进入发布授权、桌面演示和远端验收；任何新增范围都必须重新确认。

## 发布目标

交付一个可下载、可本地运行、可用于演示的 PFS 数据分析 Agent。对外只呈现 PFS 的品牌、界面、图标、文案、运行标识、安装入口和项目文档。

P0 的产品定位固定为：面向报表和经营数据的本地智能分析工作台，支持自然语言分析、受控数据查询、图表生成、多格式报告交付和结果历史回看。

## P0 必须包含

- macOS 与 Windows 的源码启动入口、安装说明和基础环境门禁。
- CSV/XLSX 数据接入、字段/范围识别、受控查询、确定性分析和图表生成。
- 一次完整的核心演示闭环：数据接入 → 分析 → 图表 → Excel/Word/PPT/Dashboard 交付 → 历史回看。
- Agent/Workflow 的现有本地可靠性边界、轻量结果留痕、来源快照和 Artifact 关联。
- Python 全量测试、Ruff、前端格式/Lint/构建、staging 和 artifact audit。
- 发布包边界检查：不包含密钥、用户数据、运行态、缓存、参考快照或旧品牌发布材料。

## 明确退役

- 商业画布（Business Canvas）
- Google Sheets

退役意味着入口、前端模块、API、Agent 工具、存储、技能、依赖和发布材料均不再作为兼容目标；不能只隐藏入口后继续把它们写成保留功能。

## 保留但默认休眠

Teams、Hooks、GPU/远程执行、飞书机器人、云端登录和真实外部 MCP 保留扩展接口，默认关闭，不自动启动，不阻塞首版 P0 发布。只有收到目标服务的可复核响应、页面或日志，才能标记为真实验收；否则只能标记为“保留”“实验性”或“待配置”。

## 本轮不作为发布门槛

多主机队列、复制存储、生产级聊天无损续跑、真实 Teams SaaS/Graph、生产规模压测、完整安全认证、签名/公证、复杂 Office 跨平台视觉和线上 live 验收。

## 验收规则

- 核心演示闭环完整验证一次。
- 每个继承目标功能做一次成功 smoke。
- 关键入口做一次打开和交互检查。
- 默认休眠能力只确认默认关闭且不会误启动，不做真实外部接入。
- 源码、固定夹具、本地真实、Docker、CI、commit、push、Release、deploy 和 live 分开记录。

## 变更控制

范围冻结后不再新增功能。若要改变退役项、休眠项、P0 门槛或验收强度，必须先同步 `docs/HANDOFF.md`、`docs/FUNCTION_COMPATIBILITY_MATRIX.md` 和本文件，再开始代码改动。

当前工作区、许可证、远端、CI、Release 和下载回读的动态状态，以 [`docs/HANDOFF.md`](HANDOFF.md) 为唯一现役入口；本文件不替代逐项能力证据。
