## 本轮已核验

- 静态页可在本地打开，页面标题为 PFS · 报表数据分析工作台。
- 静态页桌面截图检查：1280×720 视口下侧栏、主工作区、示例问题和输入区整体无明显横向溢出。
- 静态页当前为设计预览，脚本数量为 0；按钮是视觉交互稿，不代表已经绑定行为。
- Flask / 可在本地打开，页面标题为 PFS 数据分析 Agent。
- Flask 实际页面已经加载 theme_bootstrap.js、marked、DOMPurify、Vue 和 chat-app.js。
- 本轮在 `PFS_PORT=5012 .venv/bin/python app.py` 本地服务上完成 390×844（390×844 CSS 像素）真实工作台验收：
  - Skills、业务知识库、MCP 面板可以互斥切换，打开面板的 `opacity`、`pointer-events`、`aria-hidden` 和 active nav 状态一致。
  - Escape 会关闭当前面板或抽屉并恢复 Agent 导航；点击 Agent 导航也会关闭所有侧栏 surface。
